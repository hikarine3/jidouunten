# メーカー公式導線の到達性監査

確認日: 2026-09-10

`src/data/official-links.json` の35モデル・34ユニークURLを、各メーカーの日本向け商品ページまたは
過去車両の公式アーカイブに限定して確認した。全77販売単位に `maker + model` で解決でき、
全132販売単位に `maker + model` で解決でき、現行131件は `product`、現在利用不可のHonda LEGEND 1件だけは `archive` とした。今回追加したToyota シエンタの公式商品ページもHTTP 200で到達し、18販売単位へ同じ導線を解決できる。

## 到達性

- 今回追加したシエンタのグレードページ、安全ページ、主要諸元PDF、グレードJSONは取得でき、18販売単位の価格・装備・手保持条件を確認した。
- メーカー側のbot対策やHTTPクライアント差があるため、全34ユニークURLの到達性はHTTPステータスだけで判定せず、メーカーごとの通常ブラウザ確認を含む鮮度監査で追跡する。今回の追加分について、リンク切れ・別車種への遷移は確認していない。

公開UIでは確認日を表示せず、詳細と比較の判断材料の後にのみ配置する。注文可否が未確認の車両では
「新車注文できることを示すリンクではない」と明記する。過去車両には見積・注文の表現を使わない。

## 回帰gate

`npm test` の `scripts/check_official_links.mjs` で、モデルキー重複、HTTPS、種別、全販売単位への解決、
現行/過去の種別不整合をreleaseごとに検査する。実URLの到達性は鮮度監査時に再確認する。
