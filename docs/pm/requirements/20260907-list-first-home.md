# 一覧トップへの修正

根拠: 2026-09-07ユーザー「LPトップじゃないで、一覧トップにしてよ。機能優先」。
候補探索ではなく人間の指定作業。現在状態の正本はGitHub Issue/Project。

## Scope / risk / ownership

- `/`を一覧・絞り込み・比較選択の操作画面に変更し、説明LPのヒーローを外す。
- `/cars/`は互換URLとして保持し、一覧ロジックを一つにまとめる。rootのqueryはrootに保持する。
- 代表影響: `/`, `/cars/`, 車両詳細の戻る導線、`/compare/`, 共通ナビ。
- 既存車両事実・URL識別子、Consent、GTM/GA4/GSC/Bing設定、DNS、外部素材・新規依存は非変更。
- 共通ナビと一覧共通化を含むため高riskの共通UI変更として扱う。認証・Cookie・インフラの変更はしない。
- 実装writer=Luna（src/tests）、統合・独立内容/権利レビュー/公開=親（docs/GitHub/Cloudflare）。
- 同じ指定task内の役割分離とし、別Sprintのwriterは起動しない。既存方式でmainへ統合。

5. 詳細・比較・同意前非送信・5独自イベントの代表回帰を確認。
6. 件数付きtests/check/build、実ブラウザの操作と390px/1280px画像を確認してから配信。
